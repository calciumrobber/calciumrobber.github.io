# calciumrobber.github.io



This repository contains all of the Ulrich Museum of Art's Martin H. Bush Outdoor Sculpture Collection modeled in 3D to be viewed in AR.



Each folder contains all of the necessary files and images to view the model in a web browser and in AR. The web address to view the models is calciumrobber.github.io/foldername/. Most folders will just be titled the sculpture name, with the longer titles being shortened to 2-3 words.



Additionally, there will be a link to a folder to store all of the QR codes for easy access.



It has been an absolute pleasure to work with the Ulrich on this project!
